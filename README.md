# AP Schools — E-Diary & Announcement System

**Version:** 1.0.0  
**Developed by:** Team @Valiass  
**For:** AP Government Schools

---

## Overview

A Progressive Web App (PWA) for AP Government school Teachers and Cooks
to submit daily E-Diary, announcements, and meal menus — shared to
Principal via WhatsApp.

**Features:**
- 100% offline (no server, no Firebase)
- Installable on Android & iOS
- Reusable for any AP school via setup
- Government-grade premium UI
- Multi-layer security (School Secret + Login Password)
